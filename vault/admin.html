🚀 Publish Items to Live Netlify Web

Apne add kiye huye sabhi shoes & items ko Netlify par sabhi customers ke liye 100% live karein.

⚡ Method 1: 1-Click Update File (Sabse Aasan & 100% Free)

Recommended

Aapne admin panel mein jitne bhi items add ya edit kiye hain (jaise Nike SB, Jordan, photos wagera), wo is button se updated products.js file mein save ho jayenge.

Sirf yeh 2 steps karein:
  1. Neeche "💾 Save Directly to Desktop/vault/products.js" dabayein aur Save kar dein (ya Download dabayein aur Desktop/vault/ folder mein replace karein).
  2. Netlify dashboard khol kar apna vault folder drop ya redeploy kar dein — sabhi customers ko naye shoes foran live dikhenge!

🌐 Live Web Auto-Sync (Real-Time Cloud Database)

★ Recommended for 100% Automatic Updates

Yeh connect karne ke baad aap chahe apne mobile se item add karein ya laptop se — bina Netlify khole foran poori dunya ke sabhi customers ke phones par live show ho jayega!

🔥 1-Minute Free Setup (Google Firebase):
  1. console.firebase.google.com par jayein (free Google sign-in).
  2. "Add project" dabayein (project name: vault92).
  3. Left sidebar mein "Build" → "Realtime Database" par click karein aur "Create Database" dabayein.
  4. Security Rules mein "Start in test mode" select karein aur "Enable" kar dein.
  5. Uper jo URL likha aayega (jaise https://vault92-xyz-default-rtdb.firebaseio.com/), usay copy kar ke neeche paste karein aur "Save & Connect" dabayein!
